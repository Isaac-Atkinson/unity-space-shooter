## Overview

A 2D arcade-style space shooter developed in unity using C#, 
featuring wave-based enemy spawning and a power-up system.

<img src="Screenshots/Gameplay2.png" alt="Gameplay screenshot" width="700">

## Features
 
-  Player movement and shooting with responsive controls
-  Multiple enemy types with different behaviours and properties
-  Score system with local high-score saving
-  Sound effects and background music
-  Main menu, pause menu and game-over screen

## Controls
 
| Action | Key |
|---|---|
| Move | `WASD` |
| Shoot | `Left click` |
| Pause | `Esc` |

## Build the project
 
1. Clone the repo
```bash
   git clone https://https://github.com/Isaac-Atkinson/unity-space-shooter.git
```
2. Open the project in **Unity Hub** using Unity `6000.3.6f1` or a compatible version
3. Open the `MainMenu` scene in `Assets/Scenes`
4. Press ▶ Play
